# DrievDEV

My personal lil website, built it for fun, to mess around with, and to have a place that's actually mine.

## What's here

- **Home** — landing page with a sidebar showing my socials (GitHub, Twitch, YouTube, Discord) and a live status indicator that checks whether I'm streaming on [Twitch](https://www.twitch.tv/drievtv)
- **WoW Raid Calendar** — pulls upcoming raids from [Raid-Helper](https://raid-helper.xyz/) and lays them out in a 7 day calendar view

## Stack

React 19 + TypeScript, Vite, Tailwind CSS 4, React Router.
